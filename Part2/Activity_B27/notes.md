# B27 - Apply a Learned Concept in This Unit to a Real-World Application/Problem/Environment

**Date:** 18 April, 2026

## Summary
This activity involves applying a cybersecurity concept learned in CITS2006 to a real-world situation. I applied the concept of defence-in-depth to help a family friend small business in Perth set up a layered security approach for their business operations. Defence-in-depth is the idea that no single security measure is enough on its own, so multiple layers of security should be used together so that if one layer fails, the others can still protect the system.

## Application Details

### The Business
A family friend runs a small accounting practice in Subiaco, Perth with about 5 employees. They handle sensitive client financial data including tax returns, bank statements, and business records. After hearing about the ransomware attack on a local accounting firm (which I researched in Activity A16), they asked me if I could help them improve their security.

### Defence-in-Depth Layers Implemented

#### Layer 1: Network Security
I helped them configure their business router with a strong WPA3 password, changed the default admin credentials, and set up a separate guest WiFi network for visitors so that guest devices cannot access the business network where sensitive data is stored.

#### Layer 2: Endpoint Protection
I verified that all business computers had up-to-date antivirus software installed and enabled Windows Defender real-time protection. I also configured Windows Update to automatically install security patches so that the computers are always running the latest security updates.

#### Layer 3: Access Control
I helped set up individual user accounts on each computer with standard user privileges instead of admin privileges. This means that even if malware gets on the computer, it cannot make system-level changes without admin credentials. I also set up password policies requiring strong passwords with a minimum of 12 characters.

#### Layer 4: Data Backup
I set up an automated daily backup system that backs up all business files to both a local external hard drive and a cloud storage service. This way, if they are hit by ransomware, they can restore their data from the backup instead of paying the ransom.

#### Layer 5: Employee Awareness
I conducted a brief training session with all 5 employees about recognizing phishing emails and suspicious links, because human error is often the weakest link in security.

### Result
The business owner was very appreciative and said they felt much more confident about their security posture. This experience showed me how the defence-in-depth concept from CITS2006 can be directly applied to protect a real small business from cyber threats.
