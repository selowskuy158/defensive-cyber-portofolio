# B3 - Discover 3 Proactive Security Implementations in Practice

**Date:** 6 April, 2026

## Summary
This activity explores proactive security implementations, meaning security measures that are designed to prevent and detect threats before they actually cause damage rather than just reacting to incidents after they happen. Proactive security is very important in cybersecurity because waiting until an attack happens is often too late and the damage can be very costly and difficult to recover from.

## Proactive Security Implementations

### 1. Automated Software Update System (Windows Update)
Windows Update is a proactive security implementation that automatically downloads and installs security patches and updates to fix known vulnerabilities in the operating system. I observed this on my own laptop where Windows automatically installed a security update that patched a critical vulnerability in the Windows kernel. The way it works is that Microsoft continuously monitors for new vulnerabilities and releases patches, and the system automatically applies them so that users are protected even if they do not manually check for updates. This is proactive because it fixes security holes before attackers have a chance to exploit them on a wide scale.

### 2. Intrusion Detection System at UWA Network
UWA's campus network uses an intrusion detection system that continuously monitors network traffic for suspicious activity and known attack signatures. I learned about this from the IT department during a campus tour where they explained that the system automatically flags and sometimes blocks suspicious traffic such as port scanning attempts, unusual data transfers, or connections to known malicious IP addresses. This is a proactive measure because instead of waiting for a breach to happen, the system is actively looking for signs of an attack in progress and can alert the security team or take automatic action to stop it before any real damage is done.

### 3. Phishing Simulation Training at Organisations
Many organisations including some Australian companies now conduct regular phishing simulation exercises where fake phishing emails are sent to employees to test whether they click on suspicious links or open unsafe attachments. I learned about this practice from a cybersecurity seminar I attended where the speaker explained how their company uses tools like KnowBe4 to run these simulations. Employees who fall for the fake phishing emails are then directed to additional cybersecurity awareness training. This is a very effective proactive security implementation because it helps identify vulnerable employees before a real phishing attack happens, and it builds a culture of security awareness within the organisation so that people are trained to recognize threats before they become actual incidents.
