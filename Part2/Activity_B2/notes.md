## Summary

By observing strong security implementations, I can better understand what good security practices look like and how they can be applied in different contexts.

## Strong Security Implementations

### 1. Multi-Factor Authentication on Banking Apps (CommBank)
The Commonwealth Bank app on my phone uses multi-factor authentication where I need to provide my password and then also verify my identity using either a fingerprint scan or a one-time code sent to my phone. The way it works is that even if someone knows my password, they still cannot access my account without also having my physical phone and my fingerprint. This is a very strong security implementation because it adds multiple layers of protection, meaning that an attacker would need to compromise more than one factor to gain access.

### 2. Biometric Access Control at UWA Secure Labs
Some of the research labs at UWA use biometric fingerprint scanners in addition to the regular student card access. I observed this at the computer science building where certain server rooms require both a card tap and a fingerprint scan to enter. This dual authentication ensures that even if someone steals or clones a student card, they still cannot access the room without the registered fingerprint. This is a strong implementation because it combines something you have (the card) with something you are (your fingerprint).

### 3. End-to-End Encryption in Signal Messenger
Signal is a messaging app that is widely regarded as one of the most secure communication platforms available. Unlike many other apps, Signal uses the Signal Protocol for end-to-end encryption by default on all messages and calls, and the app is completely open-source meaning that anyone can inspect the code for vulnerabilities. I installed Signal and tested it by sending messages and verifying the encryption keys with my friend. The fact that it is open source and independently audited makes it a very strong security implementation compared to other messaging apps where you just have to trust the company.

### 4. Airport Security Multi-Layered Screening at Perth Airport
At Perth Airport, the security screening process involves multiple layers including boarding pass verification, metal detectors, X-ray scanning of carry-on luggage, random explosive trace detection swabs, and body scanners. I experienced this firsthand when traveling and noticed how each layer is designed to catch what the previous layer might miss. This is a very strong security implementation because it uses a defence-in-depth approach where multiple independent security measures work together, so even if one layer fails the others can still detect a threat.

### 5. Google Advanced Protection Program
Google offers an Advanced Protection Program for high-risk users that requires physical security keys for login and blocks third-party access to Gmail and Drive. I researched this program and found that it is one of the strongest account protection measures available to consumers. The way it works is that you must have a physical FIDO2 security key to log into your Google account, meaning that even if someone gets your password through phishing they cannot log in without the physical key being present. This is a very strong implementation because it eliminates the weakest point in account security which is password-only authentication.
