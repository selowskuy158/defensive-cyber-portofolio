# A15 - Discover 5 Recent Security Incidents

**Date:** 20 March, 2026

## Summary
Researched 5 recent cybersecurity incidents from 2025-2026 to understand real-world impact of cyberattacks.

## Incidents

### 1. Marks & Spencer Ransomware Attack (April 2025)
- **Attack type:** Ransomware / Social Engineering
- **Attacker:** Scattered Spider group
- **Impact:** Online shopping down for 46 days, ~£300M lost profit
- **Source:** https://www.blackfog.com/marks-and-spencer-ransomware-attack/

### 2. Qantas Airlines Data Breach (June 2025)
- **Attack type:** Third-party system compromise
- **Attacker:** Scattered Spider group
- **Impact:** ~6 million customer records stolen
- **Source:** https://www.pkware.com/blog/recent-data-breaches

### 3. University of Sydney Data Breach (December 2025)
- **Attack type:** Code repository breach
- **Impact:** ~27,000 people affected (staff, students, alumni)
- **Source:** https://www.sydney.edu.au/news-opinion/news/2025/12/18/notification-of-cyber-and-data-breach.html

### 4. Jaguar Land Rover Cyberattack (September 2025)
- **Attack type:** Software vulnerability exploitation (SAP NetWeaver)
- **Attacker:** Scattered Spider group
- **Impact:** Production halted for weeks, ~$2.5B estimated damages
- **Source:** https://thehackernews.com/2025/06/scattered-spider-behind-cyberattacks-on.html

### 5. Crunchbase Data Breach (January 2026)
- **Attack type:** Data breach
- **Attacker:** ShinyHunters cybercrime group
- **Impact:** Business data and user accounts exposed
- **Source:** https://www.pkware.com/blog/2026-data-breaches
