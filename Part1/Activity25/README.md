# A25 - Privacy-Preserving Hashing Demo

This mini project demonstrates a privacy-preserving technique for protecting personal data before storage.

## Files

- `hash_anonymizer.py` - Python script that hashes the `email` column using SHA-256
- `sample_users.csv` - Example input dataset with sample records
- `anonymized_users.csv` - Output file generated by the script with hashed email addresses

## How to Run

```bash
python3 hash_anonymizer.py sample_users.csv anonymized_users.csv
```

## Purpose

The goal is to show how personal data such as email addresses can be transformed into irreversible hash values before being stored or shared. This helps reduce privacy risk if a dataset is exposed.
