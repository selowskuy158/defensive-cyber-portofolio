# A23 - Enhance the Cybersecurity at Your Home

**Date:** 29 March, 2026
**Location:** Home, Mount Lawley, Perth, Western Australia

## Summary
This activity explores practical cybersecurity improvements that can be implemented in a home network environment, meaning that I took several concrete steps to improve security where I live. I identified vulnerabilities in my home network and implemented three important security enhancements to protect my family's devices and personal information from cyber threats.

## Security Enhancement 1: WiFi Router Password and Encryption

**What I did:** I accessed my WiFi router settings from a laptop and changed the network password from the default password that came with the router. The way it works is that default passwords are often publicly known for specific router models, making it very easy for anyone nearby to connect to the network, so I created a strong password using a combination of uppercase letters, lowercase letters, numbers, and special characters.

**The encryption upgrade:** I also enabled WPA3 encryption on the router, which is the latest and most secure WiFi encryption standard available. I noticed that the router was previously using WPA2, which is still reasonably secure but WPA3 provides better protection against modern attacks, particularly brute-force attacks and dictionary attacks on WiFi passwords.

**Why this matters:** Our household has multiple connected devices including laptops, phones, and smart home devices, meaning that an unsecured network could allow attackers to intercept traffic, steal passwords, or access files on any of these devices. Having a strong password and modern encryption really helps protect against unauthorized access to our home network.

## Security Enhancement 2: Two-Factor Authentication on Family Email Accounts

**What I did:** I set up two-factor authentication (2FA) on the email accounts of my parents and younger sibling. The way this works is that 2FA requires two separate verification steps when logging in, so meaning that even if someone obtains your password, they cannot access your email without the second factor.

**Implementation details:** I configured 2FA using authenticator apps (Google Authenticator on their phones) rather than relying only on SMS, because authenticator apps are more secure than SMS-based codes. I also generated backup codes for each family member and stored these securely in case they lose access to their authenticator app, making sure that we have a recovery method.

**Family reaction:** My parents were initially hesitant about adding this extra step to logging in, because they worried it would be inconvenient. However, I explained that most logins don't trigger 2FA - it only requires the second factor when logging in from a new device or location, so the inconvenience is minimal compared to the security benefit.

**Why this matters:** Email accounts are very important for cybersecurity because they are typically linked to password recovery for other accounts, meaning that if an attacker compromises your email, they can reset passwords for your bank, social media, and other important accounts. Protecting email with 2FA is one of the most important steps a household can take.

## Security Enhancement 3: Router Firmware Update

**What I did:** I checked the router settings for available firmware updates and installed the latest firmware version available for our specific router model. The way this works is that router manufacturers periodically release updates that fix security vulnerabilities, so meaning that outdated firmware can contain known exploitable weaknesses.

**Update process:** I made sure to download the firmware from the official manufacturer's website rather than any third-party source, making sure that the file was not compromised. I also performed the update during a time when my family was not using the internet heavily, because the router needs to restart during the update process.

**Results:** After the update, I verified that the router was running the latest version and checked the release notes to understand what security fixes were included. I observed that the update addressed several remote code execution vulnerabilities that could have allowed attackers to take control of the router.

**Why this matters:** A router is the gateway to your entire home network, meaning that compromising it puts all connected devices at risk. Keeping firmware updated is very important because it ensures that known vulnerabilities are patched before attackers can exploit them.

## Overall Impact on Home Security

These three enhancements work together to create a more secure home environment. The strong WiFi password and WPA3 encryption keep unauthorized users off the network, the router firmware updates patch known vulnerabilities, and the 2FA on family email accounts protects the most critical account that links to everything else.

## Lessons Learned

This activity helped me understand that cybersecurity is not just something that large organizations need to worry about - home security is also very important. My family handles personal financial information, medical records, and sensitive communications through our home network, so protecting these is a family responsibility. I also learned that security improvements don't have to be complicated or expensive; some of the most effective measures like strong passwords and 2FA are free and relatively easy to implement.

## Conclusion

Enhancing home cybersecurity really helps protect my family's privacy and devices. These practical improvements demonstrate that cybersecurity principles apply everywhere, from large corporate networks to home WiFi networks. The work I did shows that anyone can take meaningful steps to improve their security posture.
