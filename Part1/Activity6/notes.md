# A6 - Discover Cryptographic Implementation Used Offline

**Date:** 15 March, 2026
**Location:** Perth, Western Australia

## Summary
Explored how cryptography is used in offline systems and physical devices in everyday life.

## Examples Found
1. **EMV Chip on Bank Cards (Chip-and-PIN)** - Uses cryptographic algorithms for secure transactions at payment terminals. Generates unique code per transaction.
2. **BitLocker Drive Encryption** - Windows full-disk encryption using AES. Works with TPM chip to store keys in hardware.
3. **Electronic Passport (ePassport) with RFID Chip** - Australian ePassport uses PKI cryptography and digital signatures to protect biometric data.
