# A3 - Discover Security Concepts Used at Home

**Date:** 6 March 2026
**Location:** Home, Mount Lawley, Perth, Western Australia

## Summary
This activity explores the security concepts used at home to protect people, property, and personal belongings. I observed several common physical security controls around the house that help prevent unauthorized entry and improve household safety.

## Security Concepts Observed

### 1. Front Door Deadbolt Lock
- The main front door uses a deadbolt lock that requires a key to unlock.
- This acts as the main physical barrier for preventing unauthorized access through the front entrance.
- I observed that the deadbolt extends deep into the door frame, making it more secure than a simple latch lock.

### 2. Window Locks
- Ground floor windows are fitted with window locks to prevent the windows from being opened from outside.
- This is important because windows are a common entry point if they are left unsecured.
- I checked the windows at home and confirmed that each one had a working lock installed.

### 3. Front Fence and Gate
- The front fence and gate provide an extra outer layer of physical protection before someone can even reach the house.
- The gate uses a lockable latch, which helps restrict easy entry into the property.
- I observed that this is useful for both privacy and security because it creates another barrier beyond the front door.
